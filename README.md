🎮 Random Number Guessing Game

About

A simple number guessing game developed using Python.

The computer randomly selects a secret number between 1 and 100, and the player tries to guess it.

Features

- Random number generation
- Higher and lower hints
- Counts the number of attempts
- Congratulates the player when the correct number is guessed

Technologies

- Python
- Random module

Concepts Learned

- Variables
- While loops
- If-elif-else conditions
- User input
- Random module

How to Run

python randomno.py
